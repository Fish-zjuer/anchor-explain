### 一步 = 一拍一点

讲解是一串**步骤**，每一步带若干**逻辑点**。流转方式是：

1. 先铺整段的底色（让你知道这一步讲的是哪一块）
2. 再一个一个点亮里面的逻辑点

**一次只亮一个点**是刻意的 —— 同时点亮会让人分不清"这一步的重点到底是哪个"。

### 全是视觉的，不动你的文件

高亮用的是 VS Code 原生的装饰（`TextEditorDecorationType` + `setDecorations`），
**半透明、不修改文件、不进 undo 栈**。你按 Esc 之后，屏幕上一个框都不该留下。

### 键位

| 动作 | 默认键 |
|---|---|
| 下一步 | `Alt+]` |
| 上一步 | `Alt+[` |
| 跳到指定步 | `Ctrl+Alt+W` |
| 播放 / 暂停 | `Ctrl+Shift+Space` |
| 退出、清掉所有框 | `Esc` |

都是**默认**键：在「键盘快捷方式」里搜 `Anchor` 就能改成你自己的。
状态栏与「开始」面板显示的，永远是你**实际绑定**的那个键。
